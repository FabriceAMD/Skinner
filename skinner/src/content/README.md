# Conteúdo

- `rats.json`: ratos. Cada um tem um modelo (`molar` ou `keller`) e parâmetros de comportamento.
- `lessons.json`: aulas. Cada uma define o rato, os esquemas, um critério opcional (`curriculo`) e as perguntas do caderno.

Para adicionar uma aula, copie uma entrada existente e ajuste os campos. Os esquemas aceitos são
`FR`, `VR`, `FI`, `VI`, `DRL`, `DRO` e `EXT`, com `n` (razões) ou `ms` (intervalos).
